# MotivAppte — Landing page

Página estática preparada para GitHub Pages.

## Estructura

- `index.html` — landing completa.
- `styles.css` — diseño responsive.
- `script.js` — navegación suave.
- `assets/motivappte-icon.svg` — icono/favicon.
- `assets/motivappte-og.svg` — imagen social/OG opcional.

## Publicación

Puedes colocar esta carpeta en un repositorio independiente, por ejemplo `motivappte`, y activar GitHub Pages desde `Settings > Pages`.

La URL resultante será del estilo:

`https://apptenea.github.io/motivappte/`

Después puedes cambiar el enlace de MotivAppte en la web principal de Apptenea.

## Nota

La página no depende de backend y funciona como sitio estático. Los textos de acceso anticipado apuntan al correo de Apptenea.
